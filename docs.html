Muslim Daily REST API

A production-ready Islamic backend service powering prayer notifications, Quran recitations, authenticated Hadith search, authentic Duas, and calendar transformations across mobile and web clients.

✓ Express + Node 22 ✓ Pure WASM SQLite Engine ✓ 9 Isolated Domain Databases ✓ Trilingual Dictionary & Translation (Arabic, Amharic, English) ✓ Asmaul Husna (99 Names, Trilingual) ✓ Fusha Quranic Lexicon (2,092 Entries) ✓ OpenAPI 3.0 Standard ✓ JWT Bearer Auth

🏛️ Architecture & Database Layer

Muslim Daily uses domain-partitioned databases powered by a persistent WebAssembly SQLite layer (sql.js) ensuring fast queries without native compilation dependencies.

📚 dictionary.sqlite

Trilingual lexicon spanning Arabic, Amharic (አማርኛ), and English with root indexing, part-of-speech categorization, definitions, antonyms/synonyms, and neural translation.

✨ asmaul_husna.sqlite

The 99 Beautiful Names of Allah with transliteration, Arabic text, Amharic (አማርኛ), English, deep theological explanations, and Quran/Hadith references.

📖 quran.sqlite

114 Surahs, 6,236 Ayahs, Uthmani calligraphy script, multi-language translations (Sahih International, etc.), and classical Tafsirs.

🔍 qamus.sqlite

Quranic Arabic Lexicon (Fusha): 2,092 certified entries, 947 verbs, 1,045 nouns, 100 particles, 1,091 distinct roots, 7,700 Ayah occurrences, and 39+ grammar color classes.

🕌 prayers.sqlite

Accurate astronomical prayer calculations, geographic coordinates caching, and multiple global calculation methods (MWL, ISNA, Umm Al-Qura, Egypt).

📜 hadith.sqlite

Canonical Hadith books (Sahih al-Bukhari, Sahih Muslim, Sunan an-Nasa'i), book sections, Arabic and English narrations, and daily Hadith scheduling.

🤲 dua.sqlite

Classified Dua & Dhikr catalog (Morning, Evening, Sleep, Salah, Forgiveness) with transliteration, Arabic text, and source references.

💬 quotes.sqlite

Classical Islamic wisdom, sayings of the righteous predecessors, categorized by topics (Patience, Sincerity, Wisdom).

👤 deenbot.sqlite

User accounts, prayer logs, habit streaks, fasting logs, personal reflections, bookmarks, social study groups, and calendar tasks.

🔐 Authentication & Headers

Protected endpoints require a JSON Web Token (JWT) passed in the standard Authorization HTTP header.

Authorization: Bearer <YOUR_JWT_TOKEN> Content-Type: application/json
POST /api/auth/register
Register a new user

Creates a user account and hashes the password securely using bcryptjs.

{ "username": "salman_dev", "email": "salman@example.com", "password": "StrongPassword123!" }
POST /api/auth/login
Authenticate user & issue JWT

Validates credentials and returns a signed Bearer token along with user profile information.

{ "username": "salman_dev", "password": "StrongPassword123!" }

⚡ Quickstart & Code Examples

Integrate with Muslim Daily in your preferred language or environment.

cURL

# 1. Fetch Surah Al-Fatihah curl -s "http://localhost:3000/api/quran/surahs/1" # 2. Get prayer times for Mecca curl -s "http://localhost:3000/api/prayers/times?city=Mecca&country=Saudi%20Arabia" # 3. Retrieve daily Hadith curl -s "http://localhost:3000/api/hadith/daily"

JavaScript (Fetch / Node.js)

const BASE_URL = 'http://localhost:3000'; async function loadTodayPrayerTimes(city, country) { const res = await fetch(`${BASE_URL}/api/prayers/times?city=${encodeURIComponent(city)}&country=${encodeURIComponent(country)}`); const timings = await res.json(); console.log('Prayer timings:', timings); return timings; } loadTodayPrayerTimes('Addis Ababa', 'Ethiopia');

Python (Requests)

import requests BASE_URL = "http://localhost:3000" # Convert Gregorian to Hijri calendar response = requests.post(f"{BASE_URL}/api/calendar/convert", json={ "from": "gregorian", "to": "hijri", "date": "2026-09-12" }) print("Hijri date:", response.json())

🔍 Qamus Quranic Lexicon (Fusha)

        
High-precision Quranic lexicon engine over 2,092 certified entries, 1,091 distinct roots, 7,700 Ayah occurrences, root morphology, semantic categories, and 39+ part-of-speech color classes for syntactic glossing.


        

          

            

              GET
              /qamus
            

            Lexicon information & statistics
          

          

            
Returns dataset overview, certified counts (2,092 lemmas, 947 verbs, 1,045 nouns, 100 particles, 1,091 roots), and root directories.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/entries
            

            Browse paginated lexicon entries
          

          

            
Paginated vocabulary browsing with filters for grammatical section (verb, noun, particle), category, root, and search term.

            

              
                
Query ParameterTypeDefaultDescription

              
              
                
pageinteger1Target page number

                
limitinteger20Entries per page (max 100)

                
sectionstring-Filter by: verb, noun, particle

                
categorystring-Filter by semantic category

                
rootstring-Filter by Arabic root (e.g. ر ح م)

                
searchstring-Keyword search in Arabic, transliteration, or meaning

              
            

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/search
            

            Diacritic-tolerant lexical search
          

          

            
Searches across vocalized Arabic headwords, unvocalized text, root letters, transliterations, and English meanings.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/ayah/:ref
            

            Ayah vocabulary transclusion & token spine
          

          

            
Resolves all dictionary entries and token segments occurring in any Ayah (e.g. 1:1, 9:69, 114:1) with grammatical roles and contextual senses.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/roots
            

            Catalog of 1,091 distinct Quranic roots
          

          

            
Lists distinct roots with total lemma occurrences and derived vocabulary words.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/grammar-classes
            

            Quranic Grammar syntax color ontology
          

          

            
Returns 39+ Quranic Grammar part-of-speech classes with descriptions, hex color codes, and linguistic roles for syntactic highlighting.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /qamus/daily

✨ Asmaul Husna (The 99 Names of Allah - أسماء الله الحسنى)

        
Comprehensive service providing the 99 Beautiful Names of Allah with transliterations, Arabic calligraphy script, detailed theological explanations, Quranic citations with Arabic Ayah texts, authenticated Hadith references, and full trilingual support for Arabic (العربية), Amharic (አማርኛ), and English.


        

          

            

              GET
              /asmaul-husna
            

            List all 99 Names (with multilingual support & search)
          

          

            
Returns all 99 Names of Allah. Use ?lang=am for Amharic, ?lang=en for English, ?lang=ar for Arabic, or omit for the full multilingual package.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /asmaul-husna/:identifier
            

            Lookup by Number (1-99), Transliteration, or Arabic
          

          

            
Fetches a specific Name of Allah using its canonical number (1–99), Arabic name (e.g. الرحمن), or transliteration (e.g. Ar-Rahman). Includes Quranic reference and Hadith citation.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /asmaul-husna/daily
            

            Name of the Day (Contemplation Widget)
          

          

            
Returns a deterministic Name of Allah for the current calendar date. Ideal for mobile home screen widgets and daily reflection notifications.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /asmaul-husna/random
            

            Random Name of Allah
          

          

            
Returns a random Name of Allah with theological description and scripture citations.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /asmaul-husna/search
            

            Trilingual Search (Arabic, Amharic, English)
          

          

            
Executes diacritic-tolerant search across Arabic names, Amharic Ge'ez script meanings (e.g. ንጉሥ, ሩኅሩህ, ሰላም), and English definitions (e.g. Merciful, King, Peace).

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /asmaul-husna/stats
            

            Dataset Verification & Capabilities
          

          

            
Displays certification metrics: 99 total names, 100% Quranic citation coverage, verified Hadith source matrix, and supported languages.

            

              

                
                
              

              

            

          

        


        
Code Example: Fetching in Amharic and English

        

          
// JavaScript / Node.js
const res = await fetch('http://localhost:3000/asmaul-husna/1?lang=am');
const name = await res.json();
console.log(name.transliteration); // Ar-Rahman
console.log(name.translation);     // እጅግ በጣም ሩኅሩህ
console.log(name.description);     // በዚህ ዓለም ላሉ ፍጥረታት ሁሉ ምህረቱና እዝነቱ እጅግ ሰፊና ሁሉን አቀፍ የሆነው ጌታ።
console.log(name.reference.quran); // Surah Al-Fatihah 1:3
        

      


      
      

        
📚 Trilingual Dictionary & Translation Service (Arabic, Amharic, English)

        
A comprehensive cross-referenced vocabulary and translation service bridging Arabic (العربية), Amharic (አማርኛ), and English. Features include root word analysis, grammatical part-of-speech categorization, contextual trilingual definitions, parallel examples, automatic script detection, and bidirectional translation powered by high-accuracy lexicon alignment with seamless Gemini AI fallback.


        

          

            

              GET
              /dictionary
            

            Browse & Filter Trilingual Dictionary Entries
          

          

            
Returns paginated entries with trilingual headwords, definitions, synonyms, and examples. Supports query parameters ?q=, ?lang=ar|am|en|all, ?category=, and ?pos=.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /dictionary/lookup/{word}
            

            Direct Word Lookup Across Any of the 3 Languages
          

          

            
Resolves a headword in Arabic (e.g. سَلَام or unvocalized سلام), Amharic (e.g. ሰላም or ኢማን), or English (e.g. peace, mercy).

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /dictionary/search
            

            Fuzzy & Diacritic-Tolerant Trilingual Search
          

          

            
Performs full-text search across Arabic roots, clean text, Amharic translations, English definitions, and phonetic transliterations.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /dictionary/daily
            

            Word of the Day
          

          

            
Retrieves a deterministic daily vocabulary selection for language enrichment and reflection.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /dictionary/autocomplete
            

            Typeahead Search Autocomplete
          

          

            
Provides fast instant prefix matching for search boxes across Latin, Ge'ez, and Arabic keyboards.

            

              

                
                
              

              

            

          

        


        

          

            

              POST
              /translation/translate
            

            Trilingual Translation (Arabic, Amharic, English)
          

          

            
Translates input text between Arabic, Amharic, and English. Automatically detects input language if omitted or set to "auto". Combines lexical phrase alignment with Gemini AI neural models for fluid sentence-level translations.

            

              

                
                
              

              

            

          

        


        

          

            

              POST
              /translation/detect
            

            Script & Language Detection
          

          

            
Detects Arabic, Amharic (Ethiopic script), or English (Latin script) with confidence scores and script classification.

            

              

                
                
              

              

            

          

        


        

          

            

              GET
              /translation/pairs
            

            Supported Language Pairs
          

          

            
Returns the list of 6 fully supported bidirectional language translation pairs.

            

              

                
                
              

              

            

          

        


        
Code Example: Translating Text (JavaScript)

        

          
// Translate between Arabic, Amharic, and English
const response = await fetch('http://localhost:3000/translation/translate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: 'ሰላም ለሁላችሁ ይሁን',
    sourceLang: 'am',
    targetLang: 'ar'
  })
});
const data = await response.json();
console.log('Arabic Translation:', data.translatedText); // السلام عليكم
console.log('Translation Engine:', data.engine);         // trilingual-lexicon
